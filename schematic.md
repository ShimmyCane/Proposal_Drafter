# Proposal Drafter Schematic

## Overview

This folder is the working system for organizing proposal preparation, project analysis, and studio knowledge.

## Main folders and purpose

### 01_Preparation
This is the main intake and preparation area.

Files and folders inside include:
- Proposal Framework/
  - Contains the reusable proposal framework and HTML/JSON templates for drafting proposals.
- Past Proposals/
  - Stores past proposal examples that can be reviewed for structure, language, and scope logic.
- architectural tasks.md
  - A task library that captures the common architectural subtasks seen across past projects.
- proposal consideration.md
  - A project breakdown worksheet used to analyze a new project, forecast tasks, and inform the proposal.
- proposal_flowchart_template.html
  - A visual flowchart template for starting a project and analyzing scopes of work.

### 02_Projects
This folder is intended for active or upcoming projects.

Each new project should have its own folder containing:
- project brief or notes
- scope summary
- proposal draft
- fee schedule
- project schedule
- supporting drawings or references

### 03_Feedback
This folder is for lessons learned, client feedback, and process improvements.

It should capture:
- what worked well in a project
- what caused delays or confusion
- what should be improved in future proposals

### 04_AI_workspace
This folder is for AI-generated planning documents, instructions, notes, and versioning.

It can contain:
- AI instructions for proposal drafting
- notes from project analysis
- lessons learned
- version history

---

## Recommended workflow

1. Start with a new project in 02_Projects.
2. Use 01_Preparation files to analyze the project scope and build a proposal logic.
3. Draft the proposal using the framework and template files.
4. Save project-specific documents in the relevant project folder.
5. Use 03_Feedback to capture lessons learned and improve future proposals.

---

## How the files work together

- The proposal framework defines the structure of a proposal.
- The task library helps identify the architectural subtasks involved.
- The proposal consideration worksheet helps break down a project into scope, tasks, and pricing logic.
- The flowchart template gives a visual starting-point workflow for new projects.
- Past proposals provide precedent and wording examples.

This system is designed to make proposal creation more repeatable, more thoughtful, and easier to refine over time.
