# Project Templates Reference

## Purpose
Document the lessons learned from real proposals and template work so future AI-generated drafts stay grounded in actual project scope, pricing, and delivery logic.

## Key Lessons Learned

### 1. Do not default to a broad design proposal
The Gardena example showed that a client may be asking for a limited architectural package rather than a full design commission. Generic AI language often names a broad design process even when the project is actually a permit-led or builder-specific scope.

### 2. Prompt for the project path before writing the proposal
The proposal should not assume a default path. The drafting workflow should first ask whether the project is:
- full design
- permit-led / limited architecture
- planning support
- hybrid / mixed scope

### 3. Match the template to the actual project type
Permit packages, subdivision work, duplex design, and full architecture projects all require distinct wording. A limited-services permit-set proposal should not read like a generic full design engagement.

### 4. Real scope and exclusions matter more than generic placeholders
The strongest project language clearly states:
- what is included,
- what is excluded,
- who is responsible for consultants,
- what is deferred or additional work,
- what is reimbursable versus fixed fee.

### 5. Fee logic should reflect milestone-based project reality
A fixed fee with milestone billing is often more realistic than a broad fee range when the work is permit-driven and tied to specific review and resubmission events.

## Template Variations to Preserve
- Residential / small-lot subdivision projects
- Duplex and mirrored-plan permit set packages
- Planning support and entitlement coordination
- Full design / construction document packages
- Renovation and tenant improvement work

## Template Components
- Scope variations by project type
- Fee structures by type
- Timeline patterns and milestone triggers
- Staffing and consultant responsibilities
- Exclusions, deferred submittals, and reimbursable items
