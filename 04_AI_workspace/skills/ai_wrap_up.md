# Skill: `ai_wrap_up`

## Purpose
Review the current project workspace and consolidate AI artifacts, update version records, and summarize milestone achievements.

---

## Inputs
- `projectFolder` (optional; default: current repo root)
- `scope` (optional: `"project"` | `"all"`)

---

## Outputs
- Updated or created summary file: `04_AI_workspace/ai_wrap_up.md`
- Version entry in `04_AI_workspace/versions/` (e.g., `V1.03.md`)
- Edits to `schematic.md` (version bump) and `todo.md`
- Short list of recommended next steps

---

## Steps Performed
1. Identify changes since the previous wrap-up (file creations/edits).
2. Propose and apply minor simplifications to AI files in `04_AI_workspace/`.
3. Update version logs and schematic versioning.
4. Produce an `ai_wrap_up.md` summary with timestamp and files changed.
