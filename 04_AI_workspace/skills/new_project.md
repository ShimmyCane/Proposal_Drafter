# Skill: `new_project`

## Purpose
Initialize a new project folder under `02_Projects/<Project_Name>/` with standard subdirectories (`01_Intake/`, `02_Drafts/`, `03_Final/`) and trigger the proposal intake workflow.

---

## Inputs
- `projectName` (string; required)
- `clientNotes` (optional text / brief)

---

## Outputs
- Folder structure created under `02_Projects/<Project_Name>/`
- Project intake initialized via `ai_new_draft_proposal`
