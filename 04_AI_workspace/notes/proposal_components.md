# Proposal Components

## Overview
Key components that make up an S+Y Studio proposal.

## Main Components
1. **Fee Schedule** - Pricing structure for work items
2. **Project Timeline** - Schedule with milestones and deliverables
3. **Draft Proposal** - Main proposal document with options

## Supporting Elements
- Project scope definition
- Deliverables list
- Team assignments
- Risk assessment
- Terms and conditions

## Format
- Primary: HTML/JSON with [choiceA][choiceB] options
- Similar to architectural specification format
- Multiple template versions for different project types

## Status
Partially populated (updated 2026-10-23). Archetype templates exist; the HTML/JSON `[choice]` export is not built yet.
