# Preparation Guide (Step A)

## Overview
Build the foundation for proposal templates by analyzing past work and creating reusable templates.

## Tasks
1. **Ingest past proposals** - Review historical S+Y Studio proposals
2. **Create proposal schematic** - Document what goes into a standard proposal
3. **Identify tools needed** - Fee schedule, project timeline
4. **Refine templates** - Create templates for different project types
5. **Format templates** - Export as html/json with [choiceA][choiceB] options

## Deliverables
- Proposal components document
- Template files (multiple types)
- Export formats ready for implementation
