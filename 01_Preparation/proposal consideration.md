# Proposal Consideration Framework

## Purpose

This file is meant to help turn a new project brief into a clear proposal scope. It supports three steps:

1. Break down the project into architectural subtasks
2. Forecast effort, schedule, and deliverables
3. Translate that into a proposal scope, fee, and exclusions

## 8. Special considerations by project type

### If the project is an as-built or existing conditions project
- [ ] Site evaluation is required
- [ ] As-builts are needed
- [ ] Second site visit may be needed
- [ ] Structural and MEP are excluded unless specifically included

### If the project is a change of use project
- [ ] Code analysis is required
- [ ] Occupancy and life-safety logic must be reviewed
- [ ] Permit path and approvals must be considered
- [ ] Consultant coordination may be more significant

### If the project is a tenant improvement project
- [ ] Existing conditions and field verification may be needed
- [ ] Interior scope must be clearly defined
- [ ] Consultant coordination may be limited but still important

### If the project is a new build / addition / ADU project
- [ ] Design development is likely required
- [ ] Multiple consultant scopes may need coordination
- [ ] Permit path is part of the proposal

---

## 9. Proposal drafting notes

When drafting the proposal, make sure to:
- State the project type clearly
- Define the base scope clearly
- Separate included work from additional services
- Note schedule assumptions and dependencies
- Use a professional and persuasive tone
- Keep the proposal welcoming while protecting scope
