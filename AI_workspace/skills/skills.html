AI Workspace Schematic

This document details how to use the AI workspace skills for proposal creation.

1. `/learn`

Purpose: Review conversation history and current file to update AI notes

How it works:

  • Scans the last 5 conversation items
  • Analyses the current file being worked on
  • Updates AI_workspace/notes/initial_notes.md with new insights

2. `/new_project`

Purpose: Start a new project with template population

How it works:

  • Creates a project folder in PM/Proposal
  • Populates fee schedule (fee_schedule.xlsx)
  • Generates project timeline (project_schedule.mpp)
  • Creates draft proposal (proposal.docx)

3. `/refine`

Purpose: Focus on a specific document within project context

How it works:

  • Takes a file path from PM/Proposal folder
  • Shows the document with context of current project
  • Allows for targeted edits and feedback
