# New Project Workflow (Step B)

## Overview
Process for handling a new project from intake to final approval.

## Workflow Steps
1. **Gather Information** - Interview user, ask follow-up questions
2. **Populate Fee Schedule** - Calculate project costs
3. **Populate Project Timeline** - Create schedule with milestones
4. **Populate Draft Proposal** - Use template with [options]
5. **Iterate & Refine** - Co-edit with user until satisfied

## Key Considerations
- Ask clarifying questions about project scope
- Ensure fee schedule aligns with timeline
- Present multiple options where appropriate
- Maintain user feedback loop
